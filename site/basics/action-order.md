# 轮到谁，能做什么

你在按钮位。前面三家都弃牌，只剩两位盲注玩家还没表态。为什么这个座位舒服？因为翻牌以后，你通常最后行动，能先看对手怎么做。

## 六个座位，一圈顺时针

六人桌常用顺序是：

**UTG → HJ → CO → BTN → SB → BB**

- **UTG（枪口位）**：翻前第一个行动，身后人最多。
- **HJ（劫持位）**：中间位置。
- **CO（关煞位）**：按钮右手边，已经属于后位。
- **BTN（按钮位）**：翻牌后通常最后行动。
- **SB / BB**：小盲、大盲，翻前先放入 10 / 20 积分。

五人桌会少一个前位；七人、八人桌则在前面加入 LJ、UTG+1。名称会变，按钮、盲注和顺时针方向不会变。

## 翻前和翻后，起点不同

翻前已经有盲注，所以从大盲左边第一位开始，也就是 UTG。行动顺时针绕一圈，大盲最后表态。

翻牌、转牌、河牌都从按钮左边第一位仍在牌局里的玩家开始。按钮位因此经常最后行动。

“有位置”就是这一轮在对手后面行动；“没位置”就是先行动。它说的是信息顺序，不是椅子高级。

## 你的五个基本动作

### 弃牌 Fold

放弃这一手，已经投入底池的积分不取回。弱牌、坏位置、面对强动作时，弃牌是省下后续积分的正常决定。

### 过牌 Check

这一轮还没人下注时，把行动交给下一位，同时保留自己的牌。如果前面已经有人下注，就不能过牌。

### 跟注 Call

补齐当前下注额。大盲已有 20，面对加注到 60，只需再补 40。

### 下注 Bet

本轮还没人投入时，第一个把积分放进底池。下注前要知道它希望得到什么结果。

### 加注 Raise

前面已经有人下注，再把门槛抬高。口头说“加注到 180”最清楚：180 是你的总投入，不是额外再加 180。

全押（All-in）只是把自己剩下的积分全部投入，仍然属于下注、跟注或加注的一种尺度。多人底池里如果有人积分不足，会出现边池；入门阶段先由记分工具处理。

## 第一个翻前默认线

没人入池，轮到你时，先在“弃牌”和“主动加注”之间选。入门阶段少用平跟开池；主动加注让你有两条赢法：大家弃牌，或者带着较强范围进入翻牌。

常见开池尺度是 2.5–3BB，也就是 50–60 积分。桌上跟注很多时可以略大，但别因为拿到好牌突然把尺度翻倍，那会把信息直接写在动作上。
