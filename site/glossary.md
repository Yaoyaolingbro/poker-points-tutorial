# 术语不是暗号

听到英文词，先把它还原成桌面动作。术语只是说得快，不是把简单事情说复杂。

## 位置与牌桌

| 术语 | 桌边解释 |
| --- | --- |
| BTN / Button | 庄家位；翻后通常最后行动。 |
| SB / Small Blind | 小盲位；本桌先放 10 积分。 |
| BB / Big Blind | 大盲位，也指一个大盲单位；本桌 20 积分。 |
| UTG | 枪口位；普通六人牌局翻前第一个行动。 |
| IP / OOP | 有位置 / 没位置；本轮在对手后面 / 前面行动。 |
| Heads-up | 单挑；这手只剩两位玩家。 |
| Multiway | 多人底池；翻牌后至少三位玩家仍在。 |

## 动作

| 术语 | 桌边解释 |
| --- | --- |
| Fold / Check / Call | 弃牌 / 无人下注时过牌 / 补齐当前下注。 |
| Bet / Raise | 本轮第一个下注 / 已有下注后抬高门槛。 |
| All-in | 全押；投入自己剩余的全部积分。 |
| RFI / Raise first in | 前面无人入池时主动加注。 |
| 3-bet | 对开池加注再次加注；盲注不算第一次加注。 |
| Check-raise | 先过牌，面对下注再加注。 |
| C-bet | 翻前后主动加注者在翻牌继续下注。 |

## 牌与范围

| 术语 | 桌边解释 |
| --- | --- |
| Hole cards / Board | 只属于你的两张底牌 / 公共牌面。 |
| Flop / Turn / River | 翻牌三张 / 转牌一张 / 河牌一张。 |
| Made hand / Draw | 当前已有摊牌组合 / 仍需后续牌改善。 |
| Outs | 通常能把你改善为赢家的未知牌。 |
| Dirty outs | 来了仍可能输、需要打折的 outs。 |
| Kicker | 踢脚；主体牌型相同时参与比较的边牌。 |
| Nuts | 坚果牌；当前牌面下理论最强组合。 |
| Range | 范围；对手所有合理持牌的集合。 |
| Combo | 组合；某类持牌的具体花色搭配。 |
| Blocker | 阻断牌；你手里的牌使对手某些组合变少。 |

## 数学与深度

| 术语 | 桌边解释 |
| --- | --- |
| Equity | 权益；摊牌时赢得或分到这只底池的平均份额。 |
| Pot odds | 底池赔率；跟注成本要求的最低胜率。 |
| EV / Expected value | 期望值；同一决定长期重复后的平均净结果。 |
| Implied odds | 隐含赔率；击中后可能获得的后续积分。 |
| Reverse implied odds | 反向隐含赔率；击中后仍落后并继续投入的风险。 |
| Effective stack | 有效筹码；对决玩家中较短的可用积分。 |
| SPR | 一条街开始时，有效剩余筹码除以当前底池。 |
| Value bet / Bluff | 希望更差牌跟的价值下注 / 希望更好牌弃的诈唬。 |
| Semi-bluff | 半诈唬；当前常落后，但有 outs 可以改善。 |

术语卡住时，就回到四样东西：牌面、位置、当前底池、有效筹码。
