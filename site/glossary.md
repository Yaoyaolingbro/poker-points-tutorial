# 术语不是暗号

听见一个英文词，先把它还原成桌面动作。术语的作用是说得快，不是把简单事情说复杂。

## 位置与牌桌

| 术语 | 桌边解释 |
| --- | --- |
| BTN / Button | 按钮位；翻后通常最后行动。 |
| SB / Small Blind | 小盲位；本桌先放 10 积分。 |
| BB / Big Blind | 大盲位，也指一个大盲单位；本桌 20 积分。 |
| UTG | 枪口位；六人桌翻前第一个行动。 |
| HJ / Hijack | 劫持位；六人桌中间位置。 |
| CO / Cutoff | 关煞位；按钮右边的后位。 |
| IP / In Position | 有位置；这一轮在对手后面行动。 |
| OOP / Out of Position | 没位置；这一轮先行动。 |
| Heads-up | 单挑；这一手只剩两位玩家。 |
| Multiway | 多人底池；翻牌后至少三位玩家仍在。 |

## 动作

| 术语 | 桌边解释 |
| --- | --- |
| Fold | 弃牌。 |
| Check | 过牌；无人下注时把行动交出去。 |
| Call | 跟注；补齐当前门槛。 |
| Bet | 下注；本轮第一个投入。 |
| Raise | 加注；已有下注后抬高门槛。 |
| 3-bet | 第三次抬高门槛：盲注不算，开池加注是第一次，随后再加注通常称 3-bet。 |
| All-in | 全押；投入自己剩余的全部积分。 |
| Check-raise | 先过牌，面对下注再加注。 |
| C-bet / Continuation bet | 持续下注；翻前主动加注者在翻牌继续下注。 |

## 牌与范围

| 术语 | 桌边解释 |
| --- | --- |
| Hole cards | 底牌；只属于你的两张牌。 |
| Board | 公共牌面。 |
| Flop / Turn / River | 翻牌三张、转牌一张、河牌一张。 |
| Made hand | 成牌；当前已有对子、顺子、同花等可摊牌组合。 |
| Draw | 听牌；还需后续牌改善。 |
| Outs | 通常能把你改善为赢家的未知牌。 |
| Kicker | 踢脚；主体牌型相同时参与比较的边牌。 |
| Nuts | 坚果牌；当前公共牌下理论上最强的组合。 |
| Range | 范围；对手所有合理持牌的集合，不是你猜中的一手牌。 |
| Combo | 组合；某种持牌的具体花色搭配。 |
| Blocker | 阻断牌；你手里的牌让对手某些组合变少。 |

## 数学与深度

| 术语 | 桌边解释 |
| --- | --- |
| Equity | 权益；走到摊牌时赢得或分到这只底池的份额。 |
| Pot odds | 底池赔率；跟注成本对应的最低所需胜率。 |
| Implied odds | 隐含赔率；击中后可能获得的后续积分。 |
| Reverse implied odds | 反向隐含赔率；击中后仍落后并继续投入的风险。 |
| Effective stack | 有效筹码；对决玩家中较短的可用积分。 |
| SPR | 筹码底池比；一条街开始时有效剩余筹码除以底池。 |
| Value bet | 价值下注；希望更差牌跟注。 |
| Bluff | 诈唬；希望更好牌弃牌。 |
| Semi-bluff | 半诈唬；当前常落后，但有 outs 可以改善。 |

看到术语却无法还原动作，就回到牌面、位置、底池和有效筹码。那四样才是真正的信息。
