# A9o 在庄家位能开，枪口位为什么常常要扔？

两手牌都是 100BB，前面无人入池。枪口位身后还有五个人，庄家位只剩两名盲注玩家。牌没变，尚未行动的人数变了。

这就是翻前范围随位置变宽的原因。

## 前面无人入池：加注或弃牌

入门阶段先用 raise first in：轮到你时前面无人投入，就在主动加注和弃牌之间选。本站 10/20 积分桌可先用 50–60 的统一开池尺度。

枪口位范围紧，因为身后每个人都可能拿到更强牌。庄家位可以更宽：即使被跟注，翻牌后也通常最后行动。小盲只有大盲一人尚未表态，但翻牌后处在不利位置，所以不能照搬庄家范围。

颜色不是“这手牌必胜”。它只说明在这个简化局面里，这类牌可以作为学习起点主动进入底池。

## 前面已经加注：重新开始计算

有人加注以后，你不再面对空白局面。对手的起始位置、加注尺度和身后人数都会改变继续范围。

强对子和 AK 常能继续；中等对子、AQ、同花大牌要看位置与尺度；容易被支配的非同花 A、K 会迅速失去价值。大盲已经投入 20，价格通常较好，却要在翻牌后先行动，这两点要一起算。

跟注不是“觉得还能看”。说清楚三件事：要补多少积分、对手大致用哪些牌加注、翻牌后自己是否容易把权益实现出来。

## 先把五组牌记成形状

大对子是直接牌力；同花大牌兼顾高对和高同花；非同花大牌组合更多，却少一条成花路径；小对子主要寻找三条；同花连张靠顺子与同花潜力，但常在没中时退出。

不用一次背完 169 格。先记 AA–JJ、AKs、AKo、AQs、AJs、KQs 这些锚点，再比较相邻牌为什么多一个踢脚、同花或连接性。

判断题：庄家位前面无人入池，你拿 A9o；换成枪口位，计划应完全一样吗？不一样，枪口身后的人更多，学习范围要收紧。下一章进入翻牌后的第一组必背数字：4、8、9 个 outs 到底有多少机会击中。
