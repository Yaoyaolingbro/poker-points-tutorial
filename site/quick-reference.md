# 上桌前的两分钟速查

牌已经洗好。你只来得及看一页，就看这里。

## 本桌基准

- 5–8 人，默认 6 人。
- 小盲 10，大盲 20。
- 1BB = 20 积分；100BB = 2000 积分。
- 只在两手之间补充积分；打牌期间不主动减少桌面积分。
- 有效筹码 = 参与这次对决的最短筹码。

## 牌型从大到小

皇家同花顺 → 同花顺 → 四条 → 葫芦 → 同花 → 顺子 → 三条 → 两对 → 一对 → 高牌。

最后永远只选最好的五张。花色不分高低，完全相同就平分。

## 六人桌位置

UTG → HJ → CO → BTN → SB → BB。

翻前从 UTG 开始；翻后从按钮左边第一位仍在牌局里的玩家开始。BTN 翻后通常最后行动。

## 尺度换算

- 2.5BB = 50 积分
- 3BB = 60 积分
- 5BB = 100 积分
- 10BB = 200 积分
- 50BB = 1000 积分

## 听牌心算

- 同花听牌通常 9 outs。
- 两头顺子通常 8 outs。
- 卡顺通常 4 outs。
- 翻牌到河牌：outs × 4。
- 只剩一张牌：outs × 2。

## 底池赔率

<div class="pp-formula">最低胜率 = 跟注额 ÷（当前底池 + 跟注额）</div>

当前底池要包含对手刚下的积分。

## 下注四问

1. 为了让更差牌跟，还是让更好牌弃？
2. 哪些更差的牌会跟？
3. 哪些更好的牌会弃？
4. 被跟或被加注时，我赢什么、输什么？

最后一条：不确定时，少做一个没有对象的大下注。
