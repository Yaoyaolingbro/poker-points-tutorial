# 英文资源，按问题去看

不要从收藏五十个视频开始。带着一手牌或一个问题去找答案，看完再回到桌上复述决定。

链接最后核验于 **2026-09-12**。外部内容会调整；这里说明适合从哪里开始，不替课程承诺更新频率。

## 免费频道：先学怎么拆一手牌

| 频道 | 语言 | 建议起点 |
| --- | --- | --- |
| [Jonathan Little · PokerCoaching](https://www.youtube.com/@PokerCoaching) | 英语 | 搜索 beginner cash game 或 hand review。先暂停，再猜他的行动。 |
| [Crush Live Poker](https://www.youtube.com/@CrushlivePoker) | 英语 | 从 live hand call-in 开始，看多人底池与河牌大尺度。 |
| [Upswing Poker](https://www.youtube.com/@UpswingPoker) | 英语 | 学完本站 outs 后，再看 board texture、range、bet size。 |
| [Run It Once](https://www.youtube.com/@RunItOncePoker) | 英语 | 找一条完整手牌复盘，练逐街记录范围，而不是只看结果。 |

看视频时，每到行动点就停一下，写出自己的动作和尺度。讲者亮答案前，先列三组牌：你赢的、接近的、输的。如果他的牌局人数、位置或有效筹码不同，结论也可能不同。
