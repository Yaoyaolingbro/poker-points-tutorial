# 章节审稿：牌型从大到小

- 路由：`/basics/hand-rankings`
- 开场问题：公共牌 9♠ 8♠ 7♦ 2♣ 2♥，10♣6♣ 与 A♠K♠ 谁赢。
- 明确答案：10♣6♣ 用 10、9、8、7、6 组成顺子；A♠K♠ 只有一对 2。
- 本章唯一主规则：先比牌型；牌型相同，再从决定牌力的最高部分依次比较。
- 图示作用：`HandRanks` 用十组五张牌展示完整顺序；`RankOrderQuiz` 把开头牌例改成先作答、再揭晓。
- 比较过程：正文逐类说明同牌型比较顺序，并用“两对 A 和 8 的 K/Q 踢脚”示范比较何时停止。
- 常见误判：把两张黑桃看成同花、把手里的 A 塞进无关顺子、用花色或第六张破局。
- 练习与反馈：三个答案按钮在点击前隐藏解释；选错时提示重新数黑桃，选对时给出完整五张顺子。
- 下一章连接：读者已经会比较牌型，接着学习从七张候选牌中确定最终五张。
- 概率来源：本章没有概率数据。
- 规则复核：10 高顺子大于一对；A 可用于最高或最低顺子；花色不分高低；完全相同的五张牌平分。
