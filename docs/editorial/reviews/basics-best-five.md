# 章节审稿：七张牌，只选五张

- 路由：`/basics/best-five`
- 开场问题：A♠K♦ 面对 A♣ 9♦ 7♠ 4♥ 2♣，从七张牌中选出最终五张。
- 明确答案：A♠ A♣ K♦ 9♦ 7♠，即一对 A，K、9、7 踢脚。
- 本章唯一主规则：七张候选牌只取最好的五张，第六张不能参与比较。
- 图示作用：`BestFiveChallenge` 允许读者逐张选择；四组 `HandCompareExamples` 分别展示三对、牌面四花、踢脚和公共牌平分。
- 比较过程：正文先找牌型主体，再从剩余牌中按点数补满五张；另一种检查方法是明确说出哪两张出局。
- 常见误判：把三组对子称为“三对”、把口袋对子强行加入公共牌顺子、让第六张踢脚参与比较、误解牌面四花。
- 练习与反馈：未选满五张时不能检查；最多选择五张；答案解释被选中的五张和两张出局牌；可以清空重选。
- 下一章连接：读者会确定摊牌结果以后，再进入一手牌从翻前到河牌的行动过程。
- 概率来源：本章没有概率数据。
- 规则复核：A 对加 K、9、7 踢脚；三对只取两组最大对子再补踢脚；公共牌五张相同则平分；牌面四花需要一张同花色底牌。
- 积分措辞检查：`npm run check:content` 通过；本章没有货币或兑换表述。
- 套话检查：正文没有“本章将、至关重要、不难发现”等模板句。
- 移动端检查：Playwright 在 mobile-chromium 与 390×844 视口通过；七张牌在组件内部横向滚动，页面本身没有横向溢出。
- 篇幅检查：Markdown 共 1010 个字符，处于普通章节目标范围。
